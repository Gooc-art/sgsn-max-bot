# Источники и поля

## Расписание

URL по дате обычно строится так:

```text
https://<court>/modules.php?name=sud_delo&srv_num=1&H_date=DD.MM.YYYY
```

Пример:

```text
https://salehardsky--ynao.sudrf.ru/modules.php?name=sud_delo&srv_num=1&H_date=27.07.2026
```

Типовые поля расписания:

- номер дела
- время слушания
- место/зал
- информация по делу
- судья
- результат слушания
- судебные акты

## Карточка дела

Из расписания номер дела ведет на карточку вида:

```text
/modules.php?name=sud_delo&name_op=case&case_id=...&case_uid=...&delo_id=...&srv_num=1
```

В карточке полезные разделы:

- `ДЕЛО`
- `ДВИЖЕНИЕ ДЕЛА`
- `ЛИЦА`
- `СТОРОНЫ`
- `СУДЕБНЫЕ АКТЫ`

## Адвокаты

Адвокаты встречаются в разделе `СТОРОНЫ`.

Типовые роли:

- `Защитник (адвокат)`
- `Представитель`
- `Представитель потерпевшего`

Для первой версии можно выгружать все роли, где есть `адвокат` или
`представитель`, в колонку `Адвокат`.
